## About Me

I'm a developer focused on building practical software for networking, automation, and data analysis.

My approach is simple: understand the problem, engineer the solution, automate the repetitive work, and keep improving it.

- **Network Automation:** Building tools for network discovery, device interaction, monitoring, and operational workflows.
- **Software Engineering:** Developing modular applications with an emphasis on maintainability and real-world usefulness.
- **Data & APIs:** Collecting, processing, and exporting data from network infrastructure and external services.
- **Continuous Improvement:** Experimenting with technologies, refining workflows, and learning by building.

### <img src="https://img.shields.io/badge/01-CISCO%20APP-00E5FF?style=for-the-badge&labelColor=0D1117" alt="Cisco App"/>

**Network Operations, Engineered.**

A Python-based toolkit designed to simplify Cisco network administration through command-line workflows and automation.

- Discover network devices and manage device inventories.
- Collect switch status, resource usage, and environmental metrics.
- Work with network links, IP information, and DNS-related data.
- Support configuration workflows, backups, and data exports.
- Store collected information locally using SQLite.
